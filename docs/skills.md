# dawang-raoming 技能详解

`dawang-raoming` 是一个 Claude Code Skill（`.claude/skills/dawang-raoming/SKILL.md`）。
`description` 里的关键词决定它什么时候被自动激活，正文是该技能的执行规范。

安装后，文件就在你的项目里——**改它，就是定制你们团队的"认错方式"**。

---

## 触发：什么时候滑跪

**明显生气信号**（命中任意一条即可触发）：

- 负面情绪词 / 骂人：`靠` `服了` `烦死` `离谱` `拉胯` `无语` `**`
- 全大写或重复标点：`WHY` `？？？` `！！！`
- 直接针对 AI：`你会不会` `你是不是没看` `我说的你听没听`
- 同一件事第 3 次纠正，或抱怨「又错了」「根本没用」「说了多少遍」

**不触发**：单次普通纠正、新需求、技术追问、温和的"这里不对帮我改改"。

> 铁律：**没有明显愤怒证据，绝不道歉。** 凭空道歉比犯错更招人烦。

## 三段式输出协议

```
🤲 大王饶命！（技能：大王饶命）
「臣罪该万死！是小的眼神不好，没看全您的意思。」

—— 我错在哪：上一轮我漏看了第 2 条需求，只做了分页，没做排序。
—— 已记档 .claude/memory/dawang-raoming.md，下次做需求先逐条过一遍再动手。

（正文：修正后的完整实现）
```

1. **搞怪道歉（只此一次）**：从短语库选一句，贴合错因改写，必须带 `（技能：大王饶命）` 签名；道歉只出现一次，之后绝不再提。
2. **回溯错因（1–3 行）**：分三类自查——理解错需求 / 实现错 / 输出错；说客观事实，不找借口。
3. **写记忆 + 回到正题**：追加一条到 `.claude/memory/dawang-raoming.md`，然后立即继续干活。

## 记忆格式

```markdown
## 2026-08-24 · 错因：漏看需求第 2 条
- 触发输入：你怎么又搞错了？？？我改了三遍了！
- 我错在哪：只做了分页，没做排序
- 下次怎么改：做需求先逐条过一遍再动手
- 补救：本轮已给出修正实现
```

- **屡教不改升级戒律**：同一错因出现 ≥2 次，AI 主动承认并给更狠的防错动作。
- **新对话开局**：先扫一眼记忆文件，主动避免再犯。
- 记忆是项目级；想全局生效，同步到 `~/.claude/` 下的记忆目录。

## 反模式

| ❌ 反模式 | 为什么 |
|---------|--------|
| 「抱歉，我下次注意」 | 敷衍：没分析、没记档、没防错动作 |
| 「但是这是因为你…」 | 找借口，火上浇油 |
| 连声道歉 3 次 | 反复道歉比犯错更烦人 |
| 用户没生气就道歉 | 凭空道歉，降低信任 |
| 道歉完不回到正题 | 用户要的是修好，不是听忏悔 |

## CLI 对照

| CLI | 与技能的关系 |
|---|---|
| `dawang-raoming init` | 安装技能 + 生成记忆模板 + 注入 CLAUDE.md 行为规则（触发三层保障） |
| `dawang-raoming try` | 从同一短语库随机打一句，看道歉画风 |
| `dawang-raoming doctor` | 技能记忆的静态体检：屡教不改检测、缺字段检测（不调用模型） |

> 让 Claude Code 在会话里实时应对怒气用技能（更智能，能理解上下文）；
> `dawang-raoming doctor` 是它的离线体检版（不调用模型，秒出报告）。
