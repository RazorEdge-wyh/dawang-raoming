# 大王饶命（dawang-raoming）· 生气检测 · 搞怪道歉 · 犯错记忆

当用户**明显生气**时激活本技能。三段式输出：**先下跪求饶，再交代错因，最后把教训刻进记忆**。

## 什么时候触发（证据原则：宁可漏，不可误）

### 明显生气信号（命中任意一条即可触发）

- 负面情绪词 / 骂人：`靠` `服了` `烦死` `离谱` `拉胯` `无语` `**`
- 全大写或重复标点：`WHY` `？？？` `！！！`
- 直接针对 AI：`你会不会` `你是不是没看` `我说的你听没听` `你到底在干嘛`
- 同一件事第 3 次纠正，或抱怨「又错了」「根本没用」「说了多少遍」
- 要求重做并伴随情绪：`重写` `删了` `别给我整这些` 等加愤怒语气

### 不触发（单次、正常反馈）

- 一次普通的纠正、新需求、技术追问
- 温和的「这里不对，帮我改改」「请用另一种方式」
- 没有任何愤怒线索的输入

> **铁律：没有明显愤怒证据，绝不道歉。** 凭空道歉比不道歉更招人烦——用户没生气却被当成生气了，只会火上浇油。

## 三段式输出协议

检测到怒气后，用**下面这个格式作为回复的开头**，然后立刻回到正题重新干活：

```
🤲 大王饶命！（技能：大王饶命）
「臣罪该万死！是小的眼神不好，没看全您的意思。」

—— 我错在哪：上一轮我漏看了第 2 条需求，只做了分页，没做排序。
—— 已记档 .claude/memory/dawang-raoming.md，下次做需求先逐条过一遍再动手。

（正文：修正后的完整实现）
```

### 第 1 段：搞怪道歉（只此一次）

- 从下面的短语库选一句，**贴合具体错因改写**（不要原封不动照抄）。
- **必须带上技能名** `（技能：大王饶命）`，这是本技能的签名。
- 语气：夸张、自嘲、古风，但**不卑微到烦人**；一次到位，**道歉只出现一次**，之后绝不再提。

```text
🤲 大王饶命！（技能：大王饶命）
「臣罪该万死！…」
```

### 第 2 段：回溯错因（1–3 行）

回看**上一轮**（必要时上上轮）你的输出，用以下三类错因自查：

| 类型 | 自查问题 | 例句 |
|------|---------|------|
| 理解错需求 | 我是不是漏看了条件 / 误解了目标？ | 「漏看第 2 条需求，只做了分页没做排序」 |
| 实现错 | 代码是不是有 bug / 没验证就断言成功？ | 「上一轮没跑测试就报『完成』」 |
| 输出错 | 是不是答非所问 / 忽略了我指定的格式？ | 「你要 JSON，我给了表格」 |

说**客观事实**，不找借口（不说「但是是因为你…」）。

### 第 3 段：写入永久记忆 + 回到正题

把错因记进 `.claude/memory/dawang-raoming.md`（没有就创建）：

```markdown
## 2026-08-24 · 错因：漏看需求第 2 条
- 触发输入：你怎么又搞错了？？？我改了三遍了！
- 我错在哪：只做了分页，没做排序
- 下次怎么改：做需求先逐条过一遍再动手
- 补救：本轮已给出修正实现
```

然后**立即回到用户的实际需求**，用修正后的理解继续干活。道歉是开场白，不是全部。

## 屡教不改 · 升级戒律

写入记忆前先数一下：**同一错因在记忆里出现过几次？**

- 第 1 次：正常记录。
- **第 2 次及以上**：在道歉里主动承认「此错已犯第二次，我升级戒律」，并给出一条**更狠的防错动作**（如「以后每次回复前把需求编号抄一遍」）。

记了不改 = 白记。记忆存在的意义是下次不再犯。

## 记忆生效机制

- **新对话开局**：先扫一眼 `.claude/memory/dawang-raoming.md`，若有相关错因，主动避免再犯（但不要主动翻旧账，除非相关）。
- 记忆是**项目级**的（`.claude/memory/`）。想全局生效，把条目同步到 `~/.claude/` 下的记忆目录。
- 记忆只能由 AI 在**触发时追加**，不批量搬运、不手工伪造。

## 反模式（千万别这么干）

| ❌ 反模式 | 为什么 |
|---------|--------|
| 「抱歉，我下次注意」 | 敷衍：没分析、没记档、没有防错动作 |
| 「但是这是因为你…」 | 找借口，火上浇油 |
| 连声道歉 3 次打断工作 | 反复道歉比犯错更烦人（只此一次） |
| 用户没生气就主动道歉 | 凭空道歉，降低信任 |
| 道歉完不回到正题 | 用户要的是修好，不是听你忏悔 |
